### Start

**From your AI agent.** Add the MCP server to Claude Code, sign in, and ask for a video. Claude, ChatGPT and Cursor connect the same way: [varg.ai/mcp](https://varg.ai/mcp).

```bash
claude mcp add --transport http varg https://mcp.varg.ai/mcp
```

**From the terminal:**

```bash
curl -fsSL https://varg.ai/install | sh
vargai login
vargai generate_video --prompt "waves at dusk" --duration 5
```

**In the browser.** Open [varg.ai](https://varg.ai), write a brief, read the price, press send. A new account gets 50 free credits.

**With agent skills** for Claude Code, Codex, Cursor and Gemini CLI:

```bash
npx -y skills add vargHQ/skills --all --copy -y
```
